批量替换

在原文与译文里做整词替换，保存时带上读到的 rev；编辑器同时改过同一份文档时，宿主会拒绝这次写入。

LLM 润色

把译文交给宿主已配置的模型润色一遍。插件写 prompt，宿主负责路由、密钥和限流； 答案只做预览，要不要写回由你决定。

只跑一个阶段

不走完整流水线，只让引擎跑到指定阶段为止，然后取回那一步的产物。插件起的任务 不会动你的字幕文档，也不会更新知识库 —— 这两样由宿主锁死。
