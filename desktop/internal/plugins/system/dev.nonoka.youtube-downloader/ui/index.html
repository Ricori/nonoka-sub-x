  1. 在浏览器里登录 YouTube。
  2. 装一个能导出 Netscape 格式 cookies.txt 的浏览器扩展（搜 “cookies.txt”，Chrome / Edge / Firefox 都有）。
  3. 打开 youtube.com，用该扩展导出当前站点的 cookies.txt。
  4. 用文本编辑器打开导出的文件，全选复制，粘贴到下面。

cookies 等同于你的 YouTube 登录态，请勿外传；退出登录或长期不用会让它失效，失效后重新导出即可。 出于安全考虑，已保存的 cookies 不会回显，重新粘贴即为替换。
